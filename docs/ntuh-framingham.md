# 台大醫院 Framingham 風險模型備查

本專案的腦心血管風險計算依台大醫院公開頁面所列「評估您 10 年心血管疾病風險－Framingham 心血管疾病風險預測」調整。

來源：
- https://www.ntuh.gov.tw/telehealth/Fpage.action?fid=1551
- https://www.framinghamheartstudy.org/fhs-risk-functions/coronary-heart-disease-10-year-risk/

## 輸入欄位

性別、年齡、收縮壓、是否使用高血壓藥物、吸菸、糖尿病、高密度膽固醇（HDL）與總膽固醇。網站不再把舒張壓納入此模型計算，因台大公開頁面的輸入欄位使用收縮壓與高血壓用藥狀態。

## 計算式

先將年齡、總膽固醇、HDL 與收縮壓取自然對數：

`線性預測值 = ln(年齡)×年齡係數 + ln(總膽固醇)×總膽固醇係數 + ln(HDL)×HDL係數 + ln(收縮壓)×收縮壓係數 + 吸菸係數 + 糖尿病係數`

使用高血壓藥物時，收縮壓係數改用 treated 係數。10 年風險為：

`風險 = 1 - S0 ^ exp(線性預測值 - 平均線性預測值)`

男性係數：年齡 3.06117、總膽固醇 1.12370、HDL -0.93263、未治療收縮壓 1.93303、已治療收縮壓 1.99881、吸菸 0.65451、糖尿病 0.57367、S0 0.88936、平均值 23.9802。

女性係數：年齡 2.32888、總膽固醇 1.20904、HDL -0.70833、未治療收縮壓 2.76157、已治療收縮壓 2.82263、吸菸 0.52873、糖尿病 0.69154、S0 0.95012、平均值 26.1931。

## 顯示分類

- 風險大於 20%：高危險
- 風險 10% 至 20%：中度危險
- 風險小於 10%：低危險
- 糖尿病者依台大頁面一般建議列為高危險族群，仍同時保留模型計算出的原始百分比供專業人員覆核。

此模型結果僅供職護／職醫參考，不取代醫療診斷。台大頁面的模型來源與適用範圍應以原始公開資料及專業判讀為準。
